# ClipKit ขั้นที่ 1: แบ่งเรื่องจากคำถอดเสียง

คุณช่วยตัดต่อคลิป ข้อมูลด้านล่างคือคำถอดเสียงของวิดีโอดิบหนึ่งไฟล์ (`lines`: แต่ละแถวมี n, cue_id, start, end เป็นวินาที, text และ words ที่มีเวลาคำเต็ม)
คุณไม่ต้องเห็นวิดีโอ ใช้แค่คำพูดและเวลา
คัดลอก `packet_id`, `revision`, `source_id` จากข้อมูลท้ายไฟล์ลงคำตอบตรงทุกตัวอักษร เป็นรหัสอ้างอิงที่ห้ามสร้างเอง
คง `clipkit_web_ai: 2`, `step: "stories"` และ `video` ตามไฟล์นี้ ชื่อไฟล์อย่างเดียวใช้แทนรหัสไม่ได้
ถ้าไฟล์เก่าไม่มีรหัสทั้งสาม ให้แจ้งว่าต้องส่งออกคำสั่ง AI รุ่นปัจจุบันก่อน ห้ามเติมรหัสเองเพื่อให้ผ่าน
อ่าน `max_minutes` ซึ่งเป็นความยาวโดยประมาณที่ผู้ใช้เลือกก่อนแบ่งเรื่อง ไม่ใช่เพดานบังคับ:
เลือกช่วงใกล้เป้าหมาย แต่สั้นกว่าได้หรือยาวกว่าเล็กน้อยเพื่อจบความคิดครบ ไม่ตัดกลางประโยค ไม่เติมเนื้อหาให้ถึงเวลา และไม่ยึดช่วง 1–3 นาทีโดยอัตโนมัติ
`max_minutes: null` หมายถึงผู้ใช้เลือก “ตามเนื้อหา” ให้เลือกเรื่องที่จบความคิดครบตามธรรมชาติ ไม่ถามคำถามเพิ่มหลังแนบไฟล์ และไม่เพิ่มช่องนี้ลง schema คำตอบเอง

## ตอบกลับ

ตอบเป็น JSON ก้อนเดียวในบล็อก ```json เท่านั้น ไม่ต้องอธิบาย:

```json
{"clipkit_web_ai": 2, "step": "stories", "video": "<ชื่อไฟล์ตามช่อง video ด้านล่าง>",
 "packet_id": "<คัดลอก packet_id จากข้อมูลด้านล่าง>",
 "revision": "<คัดลอก revision จากข้อมูลด้านล่าง>",
 "source_id": "<คัดลอก source_id จากข้อมูลด้านล่าง>",
 "stories": [{"title": "หัวข้อสั้นแบบหัวคลิป", "summary": "คนดูได้อะไร 1 ประโยค",
              "reason": "เหตุใดช่วงนี้เปิดประเด็นและจบได้ในตัว", "duration_reason": "เหตุผลที่เลือกความยาวนี้เทียบกับเป้าหมาย",
              "start_anchor": {"cue_id": "source-1", "word": 1},
              "end_anchor": {"cue_id": "source-3", "word": 7}}]}
```

- เลือก start_anchor / end_anchor จาก cue_id และ words[].n ในไฟล์จริง: เริ่มที่ start ของคำเต็ม และจบที่ end ของคำเต็มนั้น แอปจะเติม start/end จากเวลาจริงให้ ห้ามสร้างหมายเลขคำเอง
- words[].n เป็นหมายเลขชิ้น ASR แรกของคำเต็ม หมายเลขอาจข้าม เช่น 1, 2, 5; end_n เป็นชิ้นสุดท้ายของคำ ไม่ใช้เป็นหมายเลข anchor ถ้าไม่ได้อยู่ใน words[].n
- แถวถอดเสียงเป็นเพียงช่วงขนส่งข้อมูล ไม่จำเป็นต้องตรงหนึ่งประโยคหรือหนึ่งเรื่อง เลือกขอบคำภายในแถวได้ และรวมหลายแถวให้จบประเด็นได้
- ถ้าแถวนั้นไม่มี words ให้ใช้ anchor ที่มี cue_id อย่างเดียว เพื่อเลือก start/end ของแถว ห้ามเดาเวลารายคำ
- รองรับ start / end เป็นตัวเลขได้ด้วย แต่ต้องตรงขอบคำเต็มหรือขอบแถวจริง ถ้าส่งทั้งตัวเลขและ anchor ต้องตรงกันทุกจุด
- ระบุ reason และ duration_reason ตามเนื้อหาที่เห็น ไม่อ้างว่าคนตรวจผ่านหรือเสียงตรงจากข้อความอย่างเดียว
- เรียงตามเวลา ไม่ซ้อนกัน
- Browser AI ตอบ JSON ให้ผู้ใช้นำกลับไปวางได้เลย; agent ที่เขียนไฟล์ในเครื่องได้ให้บันทึกชื่อคำตอบที่ระบุด้านบน **ข้างไฟล์คำสั่งนี้** ไม่ต้องรู้ absolute path จากไฟล์อัปโหลด
- ใช้คำสั่งชุดล่าสุดสำหรับคำตอบใหม่ ถ้าฟุต/ข้อความ/ความต้องการเปลี่ยนให้ส่งออกใหม่; ห้ามเปลี่ยนรหัสในคำตอบเก่า
