# EditorKrab promo: voice-over script

`docs/brand/promo.mp4` is a 33 s vertical (1080 × 1920) motion graphic with English captions and no sound.
Record or generate these lines (for example with CapCut's text-to-speech) and place each one at its start time.
The captions on screen show the same words, so the video also works muted. This is a workflow illustration, not a recording of an editing trial. The end card labels Mac setup experimental.
