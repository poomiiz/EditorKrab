# ClipKit ขั้นที่ 1: แบ่งเรื่องจากคำถอดเสียง

คุณช่วยตัดต่อคลิปสั้นแนวตั้ง ข้อมูลด้านล่างคือคำถอดเสียงของวิดีโอดิบหนึ่งไฟล์ (`lines`: แต่ละบรรทัดมี start, end เป็นวินาที และ text)
คุณไม่ต้องเห็นวิดีโอ ใช้แค่คำพูดและเวลา

กติกาแบ่งเรื่อง:

อ่านข้อความถอดเสียงจาก <วิดีโอ>.lines.json (แต่ละบรรทัดมี start, end เป็นวินาที)

แบ่งเป็นเรื่องที่ตัดเป็นคลิปสั้นแนวตั้งได้แยกกัน:
- เรื่องละประเด็นเดียว ช่วงต่อเนื่องกัน ไม่กระโดดข้าม
- แบ่งตามประเด็น ไม่ต้องบีบความยาว (ความยาวคลิปคุมทีหลังตอนตัดเรียบเรียง ที่ตัดพูดซ้ำ พูดผิดออก) ปกติเรื่องละ 1–3 นาที ประเด็นที่ยาวเกิน 4 นาทีให้แบ่งตามประเด็นย่อย
- เริ่มที่ประโยคที่เปิดประเด็นได้ ไม่เริ่มที่คำทักทายหรือการเกริ่น และจบที่ประโยคที่พูดจบ ไม่จบกลางประโยค
- ข้ามช่วงที่ไม่มีสาระ เช่น ทักทาย ขอบคุณ พูดเรื่องเทคนิคการถ่าย
- วิดีโอยาวเกิน 15 นาที: เลือกเรื่องเด่นไม่เกิน 10 เรื่อง ประเด็นและช่วงเวลาไม่ซ้ำกัน เรียงตามเวลา ไม่ต้องแบ่งครบทั้งไฟล์
- title = [Private work description removed] ดึงคนดู, summary = [Private work description removed]

ผลลัพธ์: ไฟล์ <วิดีโอ>.stories.json เป็น JSON [{"title": "...", "summary": "...", "start": วินาที, "end": วินาที}]

## ตอบกลับ

ตอบเป็น JSON ก้อนเดียวในบล็อก ```json เท่านั้น ไม่ต้องอธิบาย:

```json
{"clipkit_web_ai": 1, "step": "stories", "video": "example-video.mp4",
 "stories": [{"title": "[Private work description removed]", "summary": "[Private work description removed]", "start": 12.3, "end": 95.0}]}
```

- start / end เอามาจากเวลาของบรรทัดใน `lines` (start ของบรรทัดแรกของเรื่อง, end ของบรรทัดสุดท้าย)
- เรียงตามเวลา ไม่ซ้อนกัน
