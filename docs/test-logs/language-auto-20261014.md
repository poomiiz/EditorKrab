# UI English และตรวจภาษาเสียงอัตโนมัติ

ค่าเริ่มต้น UI เป็น English อยู่แล้วใน `ui.js` และยังจำตัวเลือกไทยของผู้ใช้ไว้ รอบนี้ตรวจหน้าเข้าสู่ระบบที่ 1280×720 และ 375×844 ไม่มีการล้นแนวนอน เพิ่มการแปลข้อความแทนรูป และปรับปุ่มสลับภาษาให้สูง 44px

ภาษาเสียงเป็นคนละค่ากับ UI: `speech_language` ใช้ `auto` เป็นค่าเริ่มต้นทั้งตัวอย่าง config แอปและ CLI ตรวจจากเสียงหลายช่วงแล้วส่งภาษานั้นให้ Whisper ถ้าผู้ใช้ระบุภาษาเองจะใช้ค่าที่ระบุ

ทดลองกับต้นฉบับ 148 นาที 10.97 วินาทีบน RTX 3070 Ti Laptop 8GB, Python 3.12.10, รุ่นฐาน 0.29.1 (`21c5f81`) ทั้ง large-v3 และ large-v3-turbo ถอดเสียงทั้งไฟล์สำเร็จและหยุด WAIT เพื่อเลือกเรื่องต่อ

| โมเดล | เวลาถอดเสียงเมื่อระบุไทยเหมือนกัน |
|---|---:|
| large-v3 | 424.77 วินาที |
| large-v3-turbo | 197.92 วินาที |

Turbo ใช้เวลาถอดเสียงน้อยลง 53.4% หรือเร็วกว่า 2.15 เท่าในรอบนี้ ไม่ใช่ผลเวลาคนตัดต่อ และตารางนี้ไม่รวมเวลาตรวจภาษาอัตโนมัติ

Turbo ตรวจภาษาไฟล์นี้ได้ความเชื่อมั่นต่ำ (ไทย 0.43) จึงเพิ่มการตรวจซ้ำด้วย large-v3 ที่ติดตั้งอยู่แล้ว ใช้ไฟล์โมเดลใน cache โดยตรงบน CPU/int8 ไม่มีการดาวน์โหลดหรือเปลี่ยนโมเดลถอดเสียง การตรวจเต็มไฟล์แบบออฟไลน์ได้ `th` ใน 145.55 วินาที จากนั้นถอดช่วง 10–40 วินาทีด้วย turbo/auto ได้ภาษาไทย 7 บรรทัด หากไม่มีโมเดลตรวจซ้ำหรือยังไม่มั่นใจ จะแจ้งให้เลือกภาษาเอง

ผลตรวจโค้ดอิสระผ่านหลังแก้การโหลด cache และการเลือกอุปกรณ์ ตรวจ smoke, JavaScript syntax และ diff แล้ว หลักฐานเต็มอยู่ในโฟลเดอร์ทดลองส่วนตัว: `comparison-results.json`, `auto-detection-proof-cpu.json`, logs และภาพ UI

ยังไม่มีบทถอดอ้างอิงจากคน จึงไม่ตัดสินความแม่นยำจากจำนวนคำหรือบรรทัด ยังไม่ได้ส่งออกฉบับเต็ม 148 นาที ตรวจร่างใน CapCut หรือวัดเวลาคนตัดต่อ และยังไม่ได้เผยแพร่แพตช์นี้เป็น release ใหม่
