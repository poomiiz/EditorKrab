# EK-06: content-bound inserts and original asset preservation

Status: implementation under review. All published media below are generated fixtures. Real content relevance, spoken-word accuracy and native CapCut acceptance remain open.

## Behavior

- Browser AI, local CLI and manual editing use one verified asset catalog and placement validator. Selected files are copied into a project content-addressed cache; original files stay intact. Equal filenames or sizes cannot alias different content. Registration publishes its catalog only after all selected files verify.
- Existing v2 clip packets carry an identity-bound `operation: inserts`, selected candidate IDs, cue/whole-word anchors, real output-clock times, source bounds, ratio and ramp settings. Public packets exclude local paths and historic unselected assets. A fresh local answer waits for review; exact committed replies retain durable receipt/retry behavior.
- Users can download the prompt/transcript packet and contact sheet, then paste or load an AI/agent JSON file. Preview validates the current revision without applying it. Explicit Apply uses the existing staged transaction and preserves music, SFX, subtitles and footage. A reply pasted into the ordinary subtitle AI panel cannot accidentally apply an insert operation.
- Each placement retains its anchor, reason, source offset, focus/crop, provenance and source SHA. One playback/geometry plan feeds FFmpeg, HyperFrames and native CapCut serialization, including shared ramp derivatives. Source bounds use the actual video stream end; longer audio cannot extend the video. Stock search returns suggestions rather than automatically choosing the first result. License status defaults to unverified.
- Cutting before an insert shifts its output anchor once; a cut through an insert is rejected before writing. Cut failures restore draft, word clocks, placements, overlays, timeline copies and seals together. Undo restores absent sidecars as well as existing files. Manual saves serialize newer edits and rebuild handlers from the accepted canonical rows.
- Canonical HyperFrames glyphs use explicit canvas wrappers, with GSAP owning their transforms. The safe-zone checker now receives the actual canvas, matching the rendered preset rather than checking the raw portrait settings. The 375px editor keeps its controls visible without horizontal page overflow.

## Verification

All **32 selected programs passed**, reporting **307 unittest cases**, plus the smoke/self-check and five Node programs. These are reported cases across programs, not a claim of 307 unique editorial scenarios. [Commands/counts/runtimes](ek06-20261015/checks.json): Python entries run as `python -X utf8 scripts/<program>` and Node entries as `node scripts/<program>`. The first matrix exposed an older lock fixture replacing the transaction module wholesale; it now patches only recovery, retaining its recover-once and word-clock assertions.

The focused cases cover stale/wrong-operation/duplicate replies, selected-candidate privacy, original retention, same-name/same-size replacements, missing/short assets, still/video source offsets, crop at 9:16/16:9/1:1, ramp consumption, cut/undo and injected I/O failures. CPU exports at three ratios verified the chosen source range/focus and retained the primary 440 Hz tone. Independent probes confirmed two edits during a pending save are serialized, duration changes retain cue anchors, and changing image to video resets the preview/offset. Clean subprocess checks of the three new core/API/export programs passed with repository/home private config reads forbidden and zero attempts; these tests used scoped fixture config.

The first pushed-head [CI run](https://github.com/poomiiz/EditorKrab/actions/runs/38731856802) passed installation but failed fixture assertions on Mac and Windows. Mac insert tests lacked scoped CapCut resource paths; Windows compared a full temporary path with its 8.3 alias. The follow-up changes only the test fixture: temporary config/resources/fonts, the actual Mac serializer exercised on every host, and filesystem identity for the derived file. All source-range, geometry, hash and ramp assertions remain. The revised 16-case program passed in **12.141 s**, with zero forbidden private-config reads; independent review passed. Current pushed-head CI is tracked in the PR checks separately from this local result.

### Actual editor and export

Playwright used the actual `editor.html`, real FastAPI video router, transaction and HyperFrames builder on an isolated localhost server with generated media. File/folder picker and lifecycle endpoints were fixture endpoints; the native CapCut process check was scoped to that generated project. Authentication and the installed user's app lifecycle were not tested.

- Downloaded the bound packet, loaded a JSON answer file, previewed it and verified that the insert list remained empty until Apply.
- Applied one insert at the supplied keyword onset **4.0 s**; music/SFX stayed unchanged. Two subsequent manual duration saves persisted the latest value and retained the keyword anchor.
- Reused a stale answer after editing: the UI retained the input, reported the revision mismatch and offered no Apply action.
- Captured actual 1440px and 375px views. At 375px the page scroll width was 360px, within the viewport; all inspected insert controls were at least 44px high. Preview desktop (file removed from the public repo), preview mobile (file removed from the public repo), manual mobile (file removed from the public repo), [UI scope/results](ek06-20261015/ui-proof.json).

The app's Export button produced an **8.0 s, 1920×1080, 30 fps H.264/AAC MP4**, fully decoded successfully. Independent sampled pixels show grey before 4 s, blue during the insert and grey afterward; the primary audio peak remains **440 Hz**. Generated MP4 (file removed from the public repo), frame at 4.5 s (file removed from the public repo), [file/hash/timing](ek06-20261015/export-proof.json), [sampled content checks](ek06-20261015/export-content-proof.json).

The final successful app export reported **23.3 s**. This excludes transcription, AI selection, manual editing, preflight/failure/retry time and human review. It is not end-to-end time or a savings claim. Earlier checks exposed the CSS/GSAP transform conflict and the incorrect raw-preset safe-zone warning; both were fixed in shared functions. The first encode attempt then stopped for low space on C; the isolated test output was moved to its existing temporary workspace volume before retry. The failed attempt's private logs were retained.

HyperFrames **0.8.101**, the app's pinned version, passed its check at six sampled times: zero runtime/layout findings, contrast **6/6**. Three `nested_structure_needs_subcomposition` lint guidance warnings remain. Eight actual browser glyph checks differed from canonical centers by at most **0.005835 px**. [Check results](ek06-20261015/hf-check.json), [geometry measurements](ek06-20261015/hf-geometry.json). The generated-media check is not all-font/all-frame or human visual approval.

## Open acceptance

- Human review of whether chosen images help real spoken content, exact real-audio timing, subject occlusion and licensing evidence.
- Open, save, reopen and play the generated draft in native CapCut. Serializer/adapter checks do not prove this.
- A watched and approved real pilot before any batch, plus the full editing-time benchmark. No customer media or paid stock was used for this evidence.
- Content-driven motion ownership, placement and cut regeneration remain EK-07. Installer, GPU/Mac hardware and release gates remain separate.
- Exact-head CI after this change is recorded separately from local results. No tag, release or deployment is authorized by this report; the history-cleanup release gate remains closed.
