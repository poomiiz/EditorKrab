# EK-05: shared subtitle clocks and measured layout

Status: implementation under review. Synthetic checks are evidence of the named cases, not editorial approval or a release.

## Behavior

- Browser AI, local imports and manual edits validate complete source wording, cue identity, options, whole-word clocks, actual canvas, preset and font before applying changes. A missing word clock permits one unchanged plain cue; it cannot support invented emphasis or phrase timing. Corrected source wording rejects retained-word reordering and ambiguous repeated-word deletion rather than choosing an onset silently.
- Normal text remains until the next phrase begins; emphasis uses the recorded word onset and remains beside the normal text. Captions are independent cue-bound text. Missing translations stay absent rather than being replaced with a supposed translation.
- One measured role plan feeds MP4/ASS, HyperFrames, native CapCut serialization and cue-bound `sentence-pair` motion. Fixed presets keep each role's size and position; overflow identifies the cue/role and requests shorter display wording or a complete-word split. Legacy nonfixed presets retain fitting behavior.
- Geometry includes the existing 1.3× pop, outline, shadow and rotation. ASS adapts font em units to the Windows font cell used by libass; it does not independently fit a phrase. Literal braces/backslashes in display text cannot inject ASS formatting. The font conversion follows the [libass font implementation](https://github.com/libass/libass/blob/master/libass/ass_font.c); literal text serialization follows the [libass parser](https://github.com/libass/libass/blob/master/libass/ass_parse.c).
- Manual source corrections, emphasis choices and captions submitted together use the existing staged transaction and receipt/recovery path. Ordinary write failures restore project metadata and native timeline copies. Correction history records its project rules; older snapshots without those rules retain the current rules because the missing history cannot be reconstructed.
- Spelling learns within the project by default, overlaid on retained machine rules. Only explicit `fix_text.py --learn-global` writes machine rules. Raw heard word labels and their times remain intact. Cached and fresh transcription apply the merged rules once from heard words; corrections cannot cascade through several replacements.
- Transcript reuse requires matching source SHA metadata and no pending transcription checkpoint. Same-size replaced sources and changes during reads are rejected. Raw-source writers serialize retranscription, and source changes during processing fail.
- The manual UI preserves cue IDs and exact numeric times for repeated text. A single Save sends source corrections, choices and any changed caption together. Cue-bound motion uses the video's actual ratio and verified events; standalone supplied pairs require real word clocks before rendering.

## Open acceptance

- Listen to independent real-audio anchors and judge source transcription, phrase meaning and emphasis timing. ASR timestamps compared with themselves do not prove alignment accuracy.
- Open, save, reopen and play the generated native CapCut draft. Native size, animation and font rendering are still unobserved; JSON/adapter checks cannot replace this gate.
- Watch and approve one real pilot before a batch. Content-driven insert/motion placement, subject occlusion, all-font/all-frame coverage and broader workflow quality remain later gates.
- No customer footage, private project or production process was modified for this evidence. No installer, GPU or Mac hardware acceptance, editing-time baseline or time-to-human-approval saving is claimed.
- Installed-app restart, human review and release authorization are separate from the passing CI. The history-cleanup release gate remains closed; no tag, release or deployment is part of this slice.
