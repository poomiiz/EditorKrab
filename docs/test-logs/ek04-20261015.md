# EK-04: story selection, manual editing and resume

Status: automated contracts passed; editorial acceptance pending. No release or deployment.

## Behavior

- Browser AI packets carry source cue IDs and complete-word clocks. A story can start/end inside an ASR transport row, at a real word boundary. Numeric times and anchors must agree.
- Browser AI, local-agent imports and manual saves use the same validator and recoverable list/binding transaction. Natural, 30 seconds and 1/2/3/5 minutes remain approximate targets. Accepted stories are never hard-split again. Actual duration, target difference and selection reasons survive import; a difference above max(15 seconds, 20%) requests review without approving or truncating anything.
- Changing source, transcript, brief or target invalidates the previous selection. Read-only revision checks do not issue packets. Historical receipts cannot restore older output. Manual saves use compare-and-swap checks; a concurrent change produces a conflict and preserves edits.
- Manual controls add, edit, split, merge adjacent stories and remove ranges. Source anchors use the original complete-word group number. Empty selection cannot silently create the whole footage. Late polls, metadata loads and focus responses cannot replace edits from another file or a newer interaction.
- CLI resume records the exact source/selection, story, shape, look, preset and font revisions. It checks the project, metadata, canvas and outside-edit seal before reuse. Old records/projects remain; incompatible revisions create a new project or report a rebuild error. `--natural` explicitly resets a saved target.
- Legacy ASR without matching metadata regenerates through the actual ASR path, retaining original transcript/meta/lines backups and resumable checkpoints. Source changes during processing fail. Pending transcription blocks new AI binding; known ASR/source hash mismatches are rejected.

Legacy unbound selections stay on disk and require explicit revalidation/save or a current import. A mechanical `--no-ai` fallback is labelled unreviewed; natural fallback includes the whole source and is not semantic story selection.

## Open acceptance

- A person must judge whether each proposed story opens clearly, develops one point and finishes without the preceding story. No external Browser AI provider answer was evaluated in this slice.
- Real-media listening, normal/emphasis/caption synchronization, ratio layout, inserts/motion and native CapCut playback still need the later quality gates and a watched pilot. Other editor screens are outside this UI check.
- No customer footage, native draft or MP4 was edited for this evidence. No batch was built and no real ASR speed, full-workflow time or time-to-human-approval saving was measured.
- Existing installed clients need updated code/restart to receive these functions. Remote CI and release acceptance are separate from these local results; the history-cleanup release gate remains closed.
