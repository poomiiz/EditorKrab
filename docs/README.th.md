# เริ่มใช้ EditorKrab

EditorKrab เป็นแอปบนเครื่องที่เปลี่ยนวิดีโอคนพูดเป็นคลิปสั้นพร้อมซับ ทำงานในเครื่องของคุณทั้งหมด วิดีโอ บทถอดเสียงและโปรเจกต์ไม่ออกจากเครื่อง

ตอนนี้เป็นรุ่นทดลองใช้ (early access) สำหรับ **Windows 10/11 เท่านั้น** ยังไม่รองรับ Mac และ Linux อ่าน[ข้อจำกัด](#ข้อจำกัด)ก่อนใช้งานจริง

[English README](../README.md) · [แจ้งปัญหา](../CONTRIBUTING.md) · [แจ้งช่องโหว่แบบส่วนตัว](../SECURITY.md)

## ติดตั้ง

1. ดาวน์โหลด `EditorKrab-windows-x64.zip` จาก [Releases](https://github.com/poomiiz/EditorKrab/releases)
2. แตกไฟล์ แล้วดับเบิลคลิก **Install EditorKrab** ตัวติดตั้งจะคัดลอกแอปไปที่ `%LOCALAPPDATA%\Programs\EditorKrab` และสร้างทางลัดบน Desktop กับ Start Menu
3. เปิด **EditorKrab** แอปจะเปิดเป็นหน้าต่างของตัวเองผ่าน Microsoft Edge ที่มากับ Windows (ใช้ Google Chrome ก็ได้)

ในไฟล์ดาวน์โหลดมี ffmpeg มาให้แล้ว ส่วนตัวถอดเสียง ([whisper.cpp](https://github.com/ggml-org/whisper.cpp)) และโมเดล Whisper large-v3 ไม่ได้แนบมา ครั้งแรกที่กดถอดเสียง แอปจะขึ้นปุ่ม **ดาวน์โหลดตัวถอดเสียง (3.1 GB)** การดาวน์โหลดหยุดได้ ต่อจากที่ค้างได้ และตรวจ checksum ทุกไฟล์ก่อนใช้

อัปเดตโดยดาวน์โหลด zip รุ่นใหม่แล้วกด **Install EditorKrab** อีกครั้ง โปรเจกต์และโมเดลเดิมยังอยู่

## ทำคลิป 6 ขั้น

1. **ใส่วิดีโอ:** เลือกไฟล์หรือทั้งโฟลเดอร์ กด **ถอดเสียง** แล้วฟังและแก้คำที่ผิด
2. **ส่งให้ AI:** ดาวน์โหลดไฟล์เดียวไปแนบในแชท AI (ChatGPT, Gemini หรือ Claude) ให้ AI เลือกช่วงที่จะเก็บ
3. **วางคำตอบ:** วางคำตอบทั้งหมดของ AI กลับเข้าแอป
4. **ซับ:** เลือกสิ่งที่จะขึ้นจอ ลากเพื่อย้าย ลากมุมเพื่อย่อขยาย
5. **หัวข้อ:** ใส่ข้อความหัวข้อและวางบนคลิป
6. **รับคลิป:** กด **สร้างคลิป** แอปทำ MP4 แนวตั้ง 9:16 ให้หนึ่งไฟล์ต่อหนึ่งเรื่องที่ AI เลือก ฝังซับและหัวข้อไว้แล้ว บันทึกใน `Videos\EditorKrab` ไม่เขียนทับไฟล์เดิม

งานบันทึกเองระหว่างทำ ปุ่ม **เลิกทำ** **ทำซ้ำ** **เปิดงาน** และ **ดาวน์โหลดสำรอง** อยู่แถบบน

## ข้อจำกัด

- **Windows เท่านั้น** ไม่มีรุ่น Mac หรือ Linux
- **ถอดเสียงด้วย CPU เท่านั้น** แม้เครื่องจะมีการ์ดจอ NVIDIA คลิปไทย 75 วินาทีใช้ 221 วินาทีบน CPU ที่เราทดสอบ
- **โมเดลเดียว** คือ Whisper large-v3
- **เลือกภาษาได้แค่ อัตโนมัติ ไทย อังกฤษ** ภาษาอื่นใช้การตรวจอัตโนมัติ ซึ่งในการทดสอบตรวจอูรดูเป็นฮินดี และมอลตาเป็นอาหรับ
- **ถอดไม่ได้ 10 ภาษา:** ฮินดี เบงกาลี ทมิฬ เตลูกู กันนาดา มราฐี คุชราตี ปัญจาบี สวาหิลี อาร์เมเนีย เพราะ Whisper วนประโยคซ้ำและแอปปฏิเสธช่วงนั้น เคยลองถอดรอบสองแล้วทำให้ภาษาไทยแย่ลงจึงเอาออก ตอนนี้ถอดรอบเดียว
- **แม่นยำต่ำ** ในมาลายาลัม เนปาล อาเซอร์ไบจาน และฮีบรู (ผิดเกิน 50%)

ผลทดสอบ 60 ภาษาด้วยเสียง Google FLEURS ผ่านครบ 6 ขั้น 50 ภาษา ผิดไม่เกิน 15% มี 24 ภาษา รายละเอียดอยู่ใน [README ภาษาอังกฤษ](../README.md#60-language-test)

## ความเป็นส่วนตัว

แอปเปิดหน้าเฉพาะที่ `127.0.0.1:8871` เครื่องอื่นเข้าไม่ได้ ข้อมูลที่ออกจากเครื่องมีแค่การดาวน์โหลดโมเดลครั้งแรก กับไฟล์ที่คุณแนบให้แชท AI เองในขั้นที่ 2

## สร้างจากซอร์ส

ต้องมี [Rust](https://rustup.rs) (stable) บน Windows แล้วรัน `cargo build --release --manifest-path rust/Cargo.toml` และ `cargo test --manifest-path rust/Cargo.toml --locked` ดูรายละเอียดใน[README ภาษาอังกฤษ](../README.md#build-from-source) แอป Python รุ่นเก่าถูกลบออกเมื่อ 25 ต.ค. 2026 ดู[เอกสารทั้งหมด](index.md)
