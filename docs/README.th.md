# เริ่มใช้ EditorKrab

EditorKrab ช่วยทำร่างคลิปสั้นจากวิดีโอคนพูด เตรียมเรื่อง ซับและปก แล้วให้คนตรวจและแก้ต่อใน CapCut หรือหน้าตัดต่อในเครื่อง

คู่มือนี้ใช้กับรุ่น 0.29.1 ตรวจรุ่นที่เผยแพร่แล้วจาก [Releases](https://github.com/poomiiz/EditorKrab/releases) ก่อนติดตั้ง Windows ใช้ขั้นตอนติดตั้งเดิม ส่วน Mac เป็นการรองรับทดลอง ต้องตรวจกับ CapCut บน Mac จริงก่อนรับรองว่าใช้งานได้ครบ

[English README](../README.md) · [เอกสารทั้งหมด](index.md)

ต้องมี Git ก่อนเริ่ม และติดตั้ง CapCut desktop แยกหากต้องการแก้โปรเจกต์ใน CapCut

## Windows

```powershell
git clone https://github.com/poomiiz/EditorKrab.git
cd EditorKrab
.\setup.cmd
```

กรอกโฟลเดอร์งานเมื่อโปรแกรมถาม จากนั้นเปิด EditorKrab จากไอคอนบน Desktop ตัวติดตั้งเตรียม Python, ffmpeg, Node.js และ dependencies ถ้าไม่พบ NVIDIA GPU จะตั้งถอดเสียงด้วย CPU

## Mac — ทดลอง

ติดตั้ง Homebrew ก่อน หรือเตรียม Python 3.12, ffmpeg และ Node.js เอง ตัว setup ตรวจโปรแกรมและใช้ Homebrew ติดตั้งส่วนที่ขาด แล้วรัน:

```bash
git clone https://github.com/poomiiz/EditorKrab.git
cd EditorKrab
bash scripts/setup.sh "$HOME/EditorKrab Workspace"
./start.command
```

เครื่องใหม่ตั้งโมเดล Whisper เป็น medium และถอดเสียงด้วย CPU ยังไม่มี Apple GPU acceleration อ่านขั้นตอนและข้อจำกัดใน [คู่มือ Mac](macos.md)

## ทำคลิปแรก

1. เลือกคลิปต้นฉบับ ตั้งภาษาพูด รูปแบบภาพและ preset ซับ
2. ทำร่างหนึ่งคลิปก่อน ถ้ามี `WAIT` ให้ทำขั้นที่ระบบขอแล้วรันต่อ
3. ตรวจเรื่อง ซับ ภาพ เสียงและปก แก้ใน CapCut ได้
4. ส่งออก MP4 แล้วเปิดดูจนจบก่อนส่งงาน

แอปต้องเข้าสู่ระบบด้วย Google ก่อนเปิดหน้าตัดต่อ การเข้าสู่ระบบจริงและระบบทีมยังมีการตรวจรับที่ค้างอยู่ รายละเอียดอยู่ใน [คู่มือทีม](team-setup.md)

## อัปเดตและวัดเวลา

ปุ่ม **Update** รับรุ่นที่เผยแพร่เป็น tag แล้ว การ merge เข้า main อย่างเดียวยังไม่ส่งไปเครื่องผู้ใช้

เปอร์เซ็นต์ประหยัดเวลาจริงยังเป็น **UNKNOWN** ใช้ [วิธีทดลอง](benchmark.md) กับ [ชีท](benchmark-sheet.csv): ต้นฉบับ 8 ตัว ความยาว 1/5/20/60 นาที คนตัด 2 คน รวม 16 รอบ ทุกครั้งต้องได้คลิปสั้นหนึ่งคลิปและผ่านเกณฑ์คุณภาพเดียวกัน จับเวลาที่คนทำงานและเวลารวมแยกกัน เก็บงานที่ไม่ผ่านไว้ด้วย

## ไฟล์และข้อมูล

เก็บคลิปต้นฉบับและโปรเจกต์ส่วนตัวนอก Git ขั้นที่ใช้ web AI ส่งข้อมูลที่คุณเลือกอัปโหลด ระบบทีมเก็บข้อมูลใน Supabase และการอัปโหลด MP4 ไป Drive ไม่เปิดสิทธิ์สาธารณะ ให้เพิ่มผู้ตรวจใน Drive เอง ลิงก์สาธารณะเดิมยังไม่ถูกเปลี่ยนสิทธิ์ ปุ่มแจ้งปัญหาเปิด GitHub ให้ตรวจและส่งเอง ไม่มีการส่งรายงานอัตโนมัติหรือแนบ log/บทถอด
